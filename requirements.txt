# Runtime dependencies for the deployed Streamlit app, and nothing else.
#
# Streamlit Community Cloud installs from this file. It is deliberately not the
# project's dependency set: dbt, LightGBM, Dagster, scipy, sklearn and the
# simulator's packages are all *build* time. They produce the warehouse; they
# are never imported by a page. Installing them would add several hundred MB
# and minutes of cold start to a container that has 1 GB and needs neither.
#
# tests/test_deployment.py derives the deployed import closure from the page
# files and fails if this list drifts from it in either direction - a missing
# package breaks the app, and an extra one is dead weight nobody notices.
#
# Pinned exactly. A portfolio app that a recruiter opens in six months should
# render the same as it does today, and a silent minor upgrade on a rebuild is
# the most likely way for that to stop being true.
